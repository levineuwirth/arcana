# Pioneer subset provenance repair
#
# Purpose
# -------
# The review correctly found that the 12-deck and 8-deck subset artifacts did not
# identify the source decklist files. Historical exact deck IDs are not recoverable
# from the committed CSVs: the pre-repair corpus loader used the MTGTop8 archetype
# header as Deck.name, so duplicate archetypes collapsed to display-name-only rows
# before the gauntlet CSV was written.
#
# Forward fix
# -----------
# arcana-ai/src/deck_corpus.rs now preserves the source file stem as LoadedDeck.source_id
# and appends it to future gauntlet Deck.name values when an About/Name header
# renames the deck:
#
#   Red Deck Wins [24148_368536]
#
# This keeps archetype substring matching usable while making future CSV rows
# uniquely traceable to converted Kaggle deck files.
#
# Historical CSV config repair
# ----------------------------
# The checked-in gauntlet CSVs now have # comment headers with the inferred runner
# config. The values are recoverable from docs plus game counts:
#
#   games/deck = 2 * paired_duels_per_pair * (n_decks - 1)
#
# For PIMC arms, the explicit PIMC budget line is included where known.
#
