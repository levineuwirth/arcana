# SAME-REFEREE CONTROL ARM (regression-to-the-mean null) — PLAN + RUNBOOK
#
# STATUS: harness + source-auditable subset are set up; the gauntlet runs below
# are NOT yet executed (results appended when they complete).
#
# WHY (review finding U5, docs/deckbuild-eval-review.md)
# ------------------------------------------------------
# The referee arm reported Gruul -0.089 and Scales +0.143 (VMC -> PIMC 16/160) as
# movement "toward real." But Gruul and Scales were selected as the VMC EXTREMES,
# so ANY independent re-measurement pulls the top down and the bottom up
# (regression to the mean) even with the SAME referee. Nothing in the arc
# calibrated that null. This control runs VMC TWICE on the same decks at two
# independent seeds; the per-bucket |VMC(seed0) - VMC(seed1)| is the null band.
# The VMC->PIMC movement is only evidence of "referee strength" to the extent it
# EXCEEDS this band.
#
# PROVENANCE NOTE
# ---------------
# The historical 8-deck referee-arm subset's exact source decklists are NOT
# recoverable (subset-provenance-PI.txt). This control therefore uses a FRESHLY
# selected, source-auditable spanning-8 (build_control_subset), not the original
# decks. It calibrates the null for the ARM DESIGN, not for those exact lists. A
# fully clean redo would also re-run PIMC 16/160 on THIS subset (commands below).
#

# READING THE RESULT
# ------------------
# Per bucket, average the 2 decks' point_rate in each CSV (or run
# placement_vs_gauntlet.py --gauntlet <csv>; its substring buckets still match the
# "[source_id]"-suffixed names). Then:
#   null_band(bucket) = | VMC_s0(bucket) - VMC_s1(bucket) |
#   arm_move(bucket)  = | VMC(bucket) - PIMC(bucket) |   (from the referee arm)
# VERDICT RULE (pre-registered here, before the run):
#   - If arm_move(Gruul) and arm_move(Scales) are LARGER than the null band on
#     BOTH buckets, the referee-arm movement survives the regression control:
#     "referee strength is a real lever" is supported.
#   - If either is WITHIN the null band, that bucket's "toward real" movement is
#     not distinguishable from same-referee re-measurement noise, and the
#     referee-arm claim for it is retracted to "not established."
# Prior effect sizes to beat (from pimc-arm-result-PI.txt): Gruul 0.089,
# Scales 0.143. Expect the VMC-VMC null at 28 games/deck to be ~0.05-0.12 per
# bucket (2 decks each), so Scales likely clears and Gruul is the close call.
